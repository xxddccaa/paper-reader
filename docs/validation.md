## 独立审查与修复

两位只读审查者分别检查 API/运维与 runner/pipeline。已处理：

- 排队后切换模型地址导致新密钥发给旧地址：解密前比对配置，显式重试刷新模型快照。
- 模型 DNS 重绑定：在真实连接时检查并使用同一批解析地址，限制 origin/path，禁止重定向。
- 模型改写 lint/review 输出、检查与实际笔记不对应、产品阶段修改已批准原生笔记：可信 host 记录、实际语义结果、输入输出哈希、精确 note/map 绑定、封存与发布复验。
- 原生封存后的初始任务无法恢复：内部状态 RPC 验证后复用原生结果，进入产品阶段。
- 用量只保留最后一次调用、失败丢失用量：逐响应累计与数据库持久化，区分尝试和任务总量。
- 饱和工作空间的长队列阻塞其他团队：筛选可运行团队后才限制候选数。
- HTML 当成 PDF 下载，以及任务完成后页面不刷新来源格式：真实 MIME、HTML attachment/CSP、发布版本触发 metadata 重取。
- 部分扫描 PDF 被误标完整：记录页级提取覆盖，OCR 路径先尝试，缺失正文只能部分结果或失败。
- 临时目录无限增长与清理首 200 行饥饿：终态保留策略及游标分页，活跃/待恢复目录不清理。
- 默认校验错误回显输入 API Key：422 只返回字段位置、错误类型与说明。

最后一次针对封存恢复与 note/map 绑定的独立复核确认两项已解决，没有残留的已确认重大问题。之后根据实际模型运行修复了工具返回过大和复核阶段循环依赖，这些属于实际适配验收发现。

收尾时再次只读核查了排队任务在解密前校验模型配置、初次发布后刷新 PDF/HTML 来源、显式重试的契约描述及对应回归，三项历史待办均确认关闭。

实际运行还发现复核模型把 2026 年的笔记创建日期误认成论文发表年份。现在所有独立评审均收到 host 当前 UTC 时间、阅读日期及字段含义；可读性检查不核查文件元数据日期，论文发表年份仍可由内容质量阶段依据原文核验。没有过滤模型判定或强行将失败改为通过。

工具额度耗尽原先会作为可恢复工具错误返回，模型可能继续循环到任务超时。现改为任务级 abort，立即终止外层与嵌套复核模型会话，并保留 `Task tool budget exhausted`；独立取消仍报告取消。真实 Pi SDK 对接刻意不停止的本地模型服务，验证耗尽后无额外请求。

实际长流程显示固定 80 次工具额度可能被原生阅读与独立复核用尽。现改为部署配置 `PAPER_READER_MAX_TOOL_CALLS`，默认 160、范围 10–500；每个阶段提示说明已用和剩余额度，全文工具明确按字符读取、默认 16,000、最大 32,000 字符，并要求沿 `next_offset` 继续。增加额度不放宽检查，任务超时独立生效。历史运行使用当时的 80 次设置，不能当作新配置的成功率统计。

独立审查又发现 Python 执行层仍保留旧常量，随后统一为任务冻结的同一额度。host/model RPC 共享单一计数入口；实际 JSONL worker 验证第 81–160 次调用正常、第 161 次致命终止，并检查当前配置变化不会覆盖任务规格。最终全后端回归 95 项通过，独立复验确认该问题已解决。

ljg-paper 固定的 `md` 分支存在上游格式不一致：指南输出 YAML/Markdown，但原始校验器仍解析 Org。adapter 1.3.0 在内存中做严格、确定的语法转换，保留原笔记、原校验器和全部语义门槛；报告绑定原笔记、研究记录与转换结果的 SHA-256。实际有效 Markdown 样例可通过原始校验器；重复字段、错误锚点、缺图、超宽图示、Org 指令注入等仍失败。研究记录引用正文的字段必须使用正文原句，不能拿英文原文摘录代替中文正文位置。独立审查发现并修复了 Unicode 换行与内联 Org 图块分隔符绕过，复验已通过。

DeepPaperNote 的图像修正路径补上固定脚本支持的 `--review-decisions` 参数，继续检查参数、内嵌文件和输出路径，并要求重新查看裁剪后的图片。模型写入 `.json` 前先验证完整语法，再原子替换；损坏 JSON 不覆盖上一份有效决策表。真实原始裁剪脚本与路径拒绝回归均通过，两位模块审查者的最终针对性复核没有残留已确认重大问题。

## 尚未由本环境证明的部分

- 宿主没有可用 Docker Compose 插件与 daemon；Compose 已静态检查，但镜像构建、容器启动和真实容器备份恢复没有实测。
- Docling 和可选 OCR 的接入与依赖锁已提供，模型缓存预下载和真实 OCR 执行尚未验证。
- 三篇论文 × 两个 skill × 三次的 18 项稳定性比较尚未执行完成。`tests/evaluate_matrix.py` 提供可重跑的矩阵，人工评分保持 pending。
- 证据摘录验证和独立模型复核不等于事实绝对正确；需要阅读质量评价表核对关键结论与跨论文条件，不能把自动通过率当作质量认证。
- 最终真实成功样本使用 guided + ljg-paper，未运行完整原生 skill、外部跨论文研究或 Docling/OCR；这些状态明确为未请求或未启用。本次 native 复核缓存改动有协议与回归覆盖，但未再次完成整套 native 真实运行。
